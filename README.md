# AVIP 2026 Task 2: Titanic EDA

This project performs a beginner-friendly exploratory data analysis of the supplied Titanic dataset.

## Contents

- `data/titanic.csv`: original dataset; not modified
- `data/titanic_cleaned.csv`: cleaned dataset generated by the notebook
- `notebooks/titanic_eda.ipynb`: cleaning, feature engineering, calculations, and visualizations
- `charts/`: saved PNG charts

## Run the notebook

From the project root:

```text
pip install -r requirements.txt
jupyter notebook notebooks/titanic_eda.ipynb
```

The notebook uses only `data/titanic.csv` as its source dataset and saves generated outputs under `data/` and `charts/`.
